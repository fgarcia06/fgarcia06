### Junior Robotics Engineer · **TRICCA Technologies**
`Jan 2024 – Dec 2025 · Edmonton, AB`

Owned the full-stack and firmware layers of an automated pipetting machine for a University of Alberta lab, built on a Klipper / Moonraker / Mainsail motion-control stack.

- Reduced manual lab intervention by **100%** across multi-step bioassay workflows via Python and C++ control modules interfacing with actuators over serial, GPIO, I2C, and SPI.
- Accelerated hardware prototyping by **40%** by developing firmware for sensor polling, motor control, and safety interlocks on Arduino and Raspberry Pi 4.
- Built a browser-based remote-control dashboard (PyShiny + HTML/CSS) enabling **3+ non-technical operators** to run the platform with no client install.
- Cut manual QA overhead by **60%** through automated Python test scripts validating positional and pipetting accuracy against acceptance criteria.
- Achieved production sign-off in **under 2 months** by leading end-to-end V&V with FDA-style traceability matrices.

`C++` `Python` `Embedded Systems` `Firmware` `Klipper` `Full-Stack` `V&V`

Applied machine learning and control theory to physical systems in a research setting.

`Python` `NumPy` `Control Systems` `Kalman Filter` `MPC` `Reinforcement Learning`
